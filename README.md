# Mama Kost Batam

Website Mama Kost Batam: kost bebas di Baloi, Nagoya, Jodoh, Pelita, dan Tropicana. Mama Hotel Pelita juga menerima penginapan per malam.

## Development

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm start
```

Built with Next.js, React, TypeScript, and Tailwind CSS. WhatsApp: 0896-7345-9682.

Interior photos are illustrations. Replace with original property photographs when available; see public/images/SOURCES.md. Confirm room prices, facilities, and availability with the business.
